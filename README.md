# TCC-Informatica-pra-Internet-2027
Trabalho de Conclusão do Curso Técnico em Informática pra Internet, conclusão em 2027 

## Descrição do Projeto - ChurchWise
O ChurchWise é um sistema web de gestão financeira desenvolvido para a Vinde Comunidade Cristã.

### Objetivo
O projeto tem como objetivo facilitar a organização e o acompanhamento das finanças da igreja, permitindo registrar entradas e saídas, consultar saldos, visualizar informações em um painel e gerar relatórios financeiros.

### Main Feature
O sistema também contará com um registro de auditoria, que permitirá rastrear alterações realizadas nos dados, aumentando a transparência e a confiabilidade das informações financeiras.
